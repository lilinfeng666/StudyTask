# StudyTask 个人学习任务管理系统

《软件工程》实验一项目。一个中文、单用户的 Flask Web 应用，用于记录课程任务、跟踪进度、筛选任务并提醒逾期和即将到期事项。

## 功能

- 新增、查看、编辑、删除任务，删除前使用独立确认页。
- 字段：任务名称、所属课程、任务描述、截止日期、优先级、状态、创建时间、更新时间。
- 支持课程、状态、优先级单独或组合筛选。
- 首页显示全部任务数、已完成数和完成率；筛选不改变全局统计口径。
- 未完成且截止日期早于今天的任务标记“逾期”；今天至未来第 3 天（含边界）标记“即将到期”；已完成任务不提醒。
- SQLite 持久化，服务重启不会清空数据。
- 服务端字段校验、SQL 参数绑定、中文错误提示和 404 页面；核心流程不依赖 JavaScript。

## 技术栈

Python 3、Flask 3、标准库 `sqlite3`、Jinja2、原生 CSS、pytest。

## 安装与启动

在 PowerShell 中进入项目目录后执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

访问 <http://127.0.0.1:5000>。默认仅监听本机，开发服务器不用于生产部署。

数据库文件位于 `instance/studytask.sqlite3`，首次启动自动建表。该目录已加入 `.gitignore`，不会提交本地任务数据。停止服务后再次执行启动命令，原有任务仍然保留。

## 运行测试


## 数据规则

| 字段 | 规则 |
|---|---|
| 任务名称 | 去除首尾空白后必填，1—100 字 |
| 所属课程 | 去除首尾空白后必填，1—60 字 |
| 任务描述 | 可选，不超过 1000 字 |
| 截止日期 | 严格的 `YYYY-MM-DD` 且必须是真实日期 |
| 优先级 | 高 / 中 / 低 |
| 状态 | 待完成 / 进行中 / 已完成 |
